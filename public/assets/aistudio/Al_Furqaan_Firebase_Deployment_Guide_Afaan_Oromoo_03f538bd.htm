AL-FURQAAN MEMBERSHIP SYSTEM

Qajeelfama Guutuu: ZIP irraa kaasee Firebase fi Cloud Run irratti qopheessuu

Sirna Buusii Miseensaa Al-Furqaan

 

Kaayyoo qajeelfama kanaa

Dokumantiin kun faayila ZIP ati ergite keessaa faayiloota dhugaan jiran irratti hundaa’a. Windows irratti projectii banuu, Node.js qopheessuu, dependencies install gochuu, Firebase Authentication fi Firestore qindeessuu, rules maxxansuu, app qorachuu fi karaa sirrii deploy gochuu tarkaanfii-tarkaanfiin ibsa.

 

Hubachiisa nageenyaa

ZIP keessa firebase-applet-config.json jira; appichi faayila kana irraa Firebase project configuration dubbisa. GEMINI_API_KEY immoo iccitii server-side dha: hin maxxansin, GitHub irratti hin olkaa’in, nama biraatti hin qoodin.

2. Waan dursee barbaachisu

· Kompiitara Windows fi internet.

· Google account kan Firebase project sanaaf hayyama qabu.

· Node.js LTS (Node 22 filatamaa) fi npm.

· ZIP file projectii kanaa.

· Firebase Console access; deploy Cloud Run yoo barbaadde Google Cloud project/billing access illee barbaachisuu danda’a.

3. ZIP extract gochuu

1. ZIP file ‘sirna-buusii-miseensaa-al-furqaan ibr.zip’ irratti right-click godhi.

2. Extract All… filadhu; folder salphaa fakkeenyaaf C:\AlFurqaanMembership keessatti extract godhi.

3. Folder keessaa package.json, server.ts, firebase-applet-config.json, firestore.rules fi src folder jiraachuu mirkaneessi.

4. Node_modules ykn dist folder ZIP keessatti hin barbaachisu; npm install isaan siif uuma.

4. Node.js fi projectii jalqabuu

Node.js LTS install godhi. Ergasii folder projectii keessatti terminal banuuf:

File Explorer → folder projectii bani → address bar irratti cmd barreessi → Enter

Ajajoota armaan gadii tartiibaan raawwadhu:

node -v
npm -v
npm install

Yoo npm install milkaa’e, appii local irratti jalqabi:

npm run dev

Projectii kana keessatti npm run dev jechuun tsx server.ts hojjechuu dha; serverichi port 3000 fayyadama. Browser keessatti:

http://localhost:3000

Terminal cufuun server dhaaba. Appii dhaabuuf Ctrl + C fayyadami.

5. Firebase project mirkaneessuu

ZIP keessaa firebase-applet-config.json keessatti Firebase project configuration duraan jira. Project ID faayila keessa jiru ‘gen-lang-client-0851355485’ dha. Kun project ati fayyadamuu barbaaddu ta’uu isaa Firebase Console keessatti mirkaneessi. Yoo project biraa fayyadamtu, Firebase Console → Project settings → General → Your apps → Web app configuration irraa values sirrii fudhadhu; faayila firebase-applet-config.json keessatti jijjiiri.

· https://console.firebase.google.com bani.

· Project ID ZIP keessaa jiru filadhu ykn project sirrii kee bani.

· Project settings keessatti Web App jiraachuu fi config isaa sirrii ta’uu mirkaneessi.

· Config file guutuu nama hin amanamneef hin ergin; API key Firebase web config keessatti argamu web app configuration dha, garuu Gemini secret waliin wal hin fakkaatu.

6. Google Authentication qindeessuu

5. Firebase Console → Build → Authentication bani.

6. Get started yoo jedhu cuqaasi.

7. Sign-in method tab filadhu.

8. Google filadhu; Enable godhi.

9. Support email filadhu; Save godhi.

Waan koodii keessaa mirkanaa’e

src/services/auth.ts keessatti signInWithPopup fi GoogleAuthProvider fayyadama. Kanaaf Google provider Firebase Authentication keessatti Enable ta’uu qaba. Koodiin OAuth scopes Drive, Sheets fi Gmail illee gaafata; Google consent screen/permissions irratti configuration dabalataa barbaachisuu danda’a.

 

7. Firestore Database uumuu fi rules maxxansuu

12. Create database cuqaasi; location projectii keetiif mijatu filadhu. Location yeroo booda jijjiiruun ulfaataa ta’uu danda’a.

13. Database erga uumamee booda Rules tab bani.

Hubachiisa guddaa: rules ammaa keessa jiru

Rules faayila ZIP keessaa jiran keessatti signed-in user hundi members, contributions fi expenses dubbisuu, uumuu fi fooyyessuu danda’a; delete gochuun admin qofaaf daangeffameera. Admin mirkaneessuun allowlist email lamaa fi admins/{uid} document irratti hundaa’a. Sirni Owner/Admin/User sadarkaa sadii guutuu ZIP kana keessatti hin argamne. Kanaaf rules kana production irratti maxxansuu dura nageenya fi role policy ogeessa waliin sakatta’i.

11. Build fi code checks

package.json keessatti ajajoonni armaan gadii qophaa’aniiru:

npm run build
npm run lint

npm run build jechuun Vite build uuma; output dist/ keessatti kaa’a. npm run lint jechuun TypeScript compiler no-emit check raawwata. Error yoo jiraate terminal output guutuu copy godhi.

Mirkaneessa

Dokumantiin kun ZIP keessaa code fi configuration sakatta’uun qophaa’e. npm install, build, deploy ykn Firebase account kee irratti hojii raawwatameera jechuu miti. Milkaa’ina hojii tokko tokko terminal/Firebase Console keessatti ofii keetiin mirkaneessuu qabda.

 

12. Production deployment: Firebase Hosting qofa moo Cloud Run?

Projectii kana keessatti React/Vite frontend qofa osoo hin taane Express server.ts illee jira. server.ts keessatti /api/gemini/grounded-search fi /api/gemini/generate-message endpoints jiru. Kanaaf Firebase Hosting static qofa irratti dist/ olkaa’uun endpoints Express kana hin hojjechiisu.

Filannoo A — Cloud Run (projectii kanaaf filannoo mijataa)

28. Google Cloud Console keessatti project Firebase waliin walqabatu filadhu.

29. Cloud Run, Cloud Build fi Artifact Registry APIs enable godhi; billing setup barbaachisuu danda’a.

30. Google Cloud SDK (gcloud) install godhi; terminal keessatti gcloud auth login fi gcloud config set project PROJECT_ID raawwadhu.

31. Project root keessatti npm install fi npm run build raawwadhu.

32. Cloud Run deploy from source irratti project root irraa gcloud run deploy al-furqaan-membership --source . --region REGION --allow-unauthenticated ajaja fayyadami; REGION bakka siif dhihoo ta’e filadhu.

33. Deployment yeroo gaafatu buildpacks/Node environment fi port settings Cloud Run default waliin hojjechuu mirkaneessi.

34. GEMINI_API_KEY Secret Manager irraa Cloud Run service irratti environment secret godhi; secret plain text koodii keessa hin kaa’in.

35. Service URL argatte browser keessatti bani; Google Authentication authorized domains keessatti domain isaa dabaluu fi Firebase config/Google OAuth settings sirreessuu barbaachisuu danda’a.

Yaadannoo deployment

Cloud Run source deployment irratti appichi npm run build raawwachuu fi start command npm run start fayyadama. Appichi server.ts keessatti PORT env variable dubbisa; Cloud Run PORT kennuuf qophaa’eera. Gcloud deployment command hojii raawwachuu dura gcloud CLI fi project permissions sirrii ta’uu mirkaneessi.

 

Filannoo B — Firebase Hosting (frontend qofa)

Yoo React frontend qofa Firebase Hosting irratti fe’uu barbaadde, dist/ directory deploy gochuu dandeessa; garuu Express/Gemini API endpoints server.ts bakka biraatti (fakkeenyaaf Cloud Run) deploy gochuun API requests gara backend sanaatti route/proxy gochuu barbaachisa. Firebase Hosting qofa appii kana guutuu hin bakka bu’u.

npm run build
# dist/ folder Firebase Hosting irratti serve godhi

Firebase Hosting qindeessuuf Firebase CLI install godhi, firebase login fi firebase init hosting raawwadhu. Public directory dist filadhu; single-page app rewrite yes filadhu. Garuu API backend routing addaan qindeessuu dagattee hin deploy godhin.

14. Rakkoolee yeroo baay’ee mudatan

Ergaa / Rakkoo

Furmaata jalqabaa

npm is not recognized

Node.js install/reinstall godhi; terminal haaraa bani; node -v fi npm -v qoradhu.

Missing GEMINI_API_KEY

.env.local keessatti key sirrii galchi; key sirrii ta’uu fi server restart gochuu mirkaneessi.

auth/unauthorized-domain

Firebase Authentication → Settings → Authorized domains keessatti localhost/domain appii dabaluu.

auth/operation-not-allowed

Authentication → Sign-in method → Google Enable godhi.

Missing or insufficient permissions

firestore.rules, login state, user UID fi admin rules sakatta’i.

Failed to fetch / API 404

Express backend Cloud Run irratti deploy ta’uu fi frontend API routing/proxy sirrii ta’uu mirkaneessi.

Build failed

Terminal error guutuu copy godhi; npm install irra deebi’i; package/version incompatibility sakatta’i.
